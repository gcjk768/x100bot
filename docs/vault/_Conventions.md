# Conventions

- Flat vault, links over folders. `Home.md` is the MOC.
- Atomic notes, one idea each. Rough notes go to `Inbox.md` first.
- Tags only for status: `#active`, `#archived`. Frontmatter `tags` and `updated` on every note.
- Update `Changelog` and `App Overview` on every code change; path qualify code references.
- Move, don't delete: retired notes go to `Archive/`.
- No dashes in prose that ends up in Telegram; this vault is for humans and may use them.
